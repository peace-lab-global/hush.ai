# Web 界面梳理与改进建议

本文档描述当前「对客前台」与「内部管理后台」的页面结构，并给出分优先级的改进方向；部分条目已在仓库中落地，见文末「已执行」。

## 一、信息架构

| 入口 | 技术形态 | 主要路径 |
|------|----------|----------|
| 对客对话 | 单页 HTML + 内联 CSS/JS，FastAPI 读文件返回 | `GET /` → `hushai/meditation/static/index.html` |
| 管理后台 | Jinja2 模板 + `admin.css` + Font Awesome | `GET /admin/*` → `hushai/meditation/admin/templates/*.html` |

对客侧通过 `POST /api/auth/dev-login` 获取 JWT，对话走 `POST /api/chat/`；会话与昵称等保存在 `localStorage`（`ll_token`、`ll_conv`、`ll_nick` 等）。

## 二、对客前台（对话窗口）

### 现状要点

- 登录层（称呼）→ 主界面：顶栏 IP、消息区、语音条、输入区与语音设置抽屉。
- 语音：浏览器 `SpeechSynthesis` / `SpeechRecognition`，音色与语速等持久化到本地。
- 背景为 Canvas 粒子动画；整体为深色冥想风格，移动端 `max-width: 480px` 单列。

### 改进建议（按优先级）

**P0 — 体验与信任**

1. **登录/网络失败反馈**：登录请求失败时除恢复按钮外，应有可见文案（如「网络异常，请重试」），避免用户无反馈。
2. **新对话入口**：长期会话下用户需要「重新开始」而不清账号；提供「新对话」并同步清空 `conversation_id` 与界面消息。
3. **刘海屏与 Home Indicator**：输入区增加 `safe-area-inset-*`，避免按钮贴底被系统手势遮挡。

**P1 — 可访问与舒适**

4. **减少动效**：尊重 `prefers-reduced-motion`，减弱或关闭粒子动画与循环 CSS 动画，减轻前庭不适。
5. **语义与焦点**：主区域 `role="main"`、关键按钮补充 `aria-label`；可见的 `:focus-visible` 轮廓，便于键盘操作。
6. **元信息**：补充 `meta description`、`theme-color`，利于分享与移动浏览器顶栏色调。

**P2 — 产品化（后续迭代）**

7. **流式回复**：若后端已支持 SSE/WebSocket，前端可逐字展示以降低等待感（需与 `chat_stream` 等 API 对齐）。
8. **非开发环境登录**：生产环境应替换 `dev-login` 为真实微信/手机号等流程，并明确隐私说明入口。
9. **离线/弱网**：发送失败时提供重试按钮，而非仅一句错误气泡。

### 已执行（对客）

- 登录失败可见提示、新对话、安全区与 `prefers-reduced-motion`、基础 a11y 与 meta、`:focus-visible`。

## 三、内部管理后台

### 现状要点

- 侧边栏：仪表盘、用户、对话、记忆、知识库、导入知识、系统设置、外链 API 调试。
- 各列表页统一表格/分页；详情页展示对话消息、用户记忆等。
- 认证：管理员 Cookie + JWT，见 `hushai/meditation/admin/README.md`。

### 改进建议（按优先级）

**P0**

1. **跳过导航链接**：首屏键盘用户可跳到主内容，符合无障碍常见做法。
2. **登录页与前台关系**：运维人员从登录页可回到对客站点根路径，便于对照调试（可选）。

**P1**

3. **面包屑**：在「用户详情 / 对话详情 / 知识详情」等深层页用面包屑标明层级，并在模板中预留 `{% block breadcrumb %}` 便于逐页填充。
4. **侧栏当前项**：已按路径高亮；若增加动态路由需注意 `active` 规则与尾部斜杠。
5. **表格空态与加载**：大数据量时考虑骨架屏或明确「加载中」状态（当前多为服务端直出，优先级可后移）。

**P2**

6. **前端资源**：Font Awesome 依赖 CDN；内网或合规环境可改为本地静态资源或子集图标。
7. **操作审计与危险操作二次确认**：删除记忆/知识等可增加确认模态与简要审计日志（偏后端与产品）。

### 已执行（后台）

- 全局跳过链接与样式、`meta description`、面包屑占位块与 `.page-breadcrumb` 样式、登录页「返回对客对话页」链接。
- 用户详情与对话详情页已填充面包屑导航示例，其它列表页可按需继承 `breadcrumb` 块。

## 四、维护说明

- 对客大段 UI 集中在 `static/index.html`，改动时注意移动端视口与内联脚本中的 API 前缀（当前为空字符串，同源）。
- 后台样式以 `hushai/meditation/admin/static/css/admin.css` 为单一事实来源，新增页面应继承 `base.html` 以保持侧栏一致。
