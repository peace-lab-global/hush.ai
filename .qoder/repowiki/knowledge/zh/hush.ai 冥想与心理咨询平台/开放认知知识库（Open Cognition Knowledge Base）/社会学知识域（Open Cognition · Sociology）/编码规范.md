- 所有 `.md` 条目统一以 YAML front matter 开头，固定字段包括 id、title、type（thinker/concept）、domain=sociology、school、era、tags、aliases、sources，供外部工具解析。
- 思想家条目 type 为 thinker，包含 birth/death 年份与 sources 原典列表；概念条目 type 为 concept，school 置 null 表示跨学派。
- 正文采用“基本信息 → 核心命题/定义 → 思想脉络/维度 → 关键著作/概念 → 思想坐标/理论谱系 → 当代应用/议题 → 常见误读 → 跨学科关联 → 进阶阅读”的固定章节顺序。
- 跨领域关联通过 `[标签] 相对路径` 的 Markdown 链接形式在“跨学科关联”小节中声明，标签如 `[发展]`、`[张力]` 表达关系语义。
