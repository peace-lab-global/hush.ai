- 每个知识条目使用 YAML front matter 声明 id、title、type、domain、tags、aliases、sources、cross-refs 等结构化元数据，正文以 Markdown 书写。
- 跨条目关联通过 cross-refs 中的 id + relation 字段表达，而非硬编码相对路径，保证引用稳定可迁移。
- 标题采用「中文 · English」双语形式，术语首次出现附带梵文/巴利文原文标注（如 Dukkha、Śūnyatā）。
- 条目结构遵循固定章节模板：一句话定义 → 提出者与背景 → 核心要义 → 通俗用法 vs 学术原义 → 代表思想家 → 应用场景 → 常见误读 → 跨学科关联 → 进阶阅读。
- 佛教认知理论子域将「概念文档」与「SKILL.md 实践技能」分置于同一目录下，形成「理论 → 技能」的成对组织方式。
