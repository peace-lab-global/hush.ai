- 所有 Markdown 文件顶部使用 YAML front matter 声明结构化元数据（id/title/type/domain/school/era/tags/sources），其中 type 严格区分 concept 与 thinker 两种文档类型。
- 正文标题层级固定为二级 `##` 分节（基本信息 / 核心命题 / 思想脉络 / 关键著作 / 重要概念 / 思想坐标 / 当代应用 / 常见误读 / 跨学科关联 / 进阶阅读），确保不同条目间结构一致。
- 跨文档引用一律使用相对路径（如 `../schools/existentialism/heidegger.md`、`../../religion/traditions/buddhism/zen.md`），不依赖绝对 URL。
- 在「跨学科关联」小节中以 `[平行]` / `[发展]` / `[对立]` 标签标明与其他领域条目的语义关系，而非简单罗列。
- 在「关联 Skills」小节中以相对路径链接到上层 `skills/` 中的 SKILL.md 卡片，使知识条目与分析方法解耦并可复用。
