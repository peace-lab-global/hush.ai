纯文档型知识域，无代码逻辑，由两层目录构成：
- `concepts/`：存放跨学派的元概念词条（如 being、dialectics、epistemology），每个文件通过 YAML front matter 标注 `type: concept`、`domain: philosophy`、`school`、`era`、`tags`、`aliases`、`sources` 等结构化字段，正文采用统一模板（一句话定义 → 提出者与背景 → 核心要义 → 现代分化 → 通俗 vs 学术 → 相关概念关系 → 代表思想家 → 应用场景 → 常见误读 → 跨学科关联 → 进阶阅读）。
- `schools/<流派>/`：按思想流派子目录组织思想家条目（如 existentialism/nietzsche.md），front matter 中 `type: thinker` 并补充 `birth`/`death` 等生平字段；正文模板为基本信息 → 核心命题 → 思想脉络分期 → 关键著作 → 重要概念 → 思想坐标（承接/批判/影响）→ 当代应用 → 常见误读 → 跨学科关联 → 进阶阅读 → 关联 Skills。
- `README.md` 充当导航索引，同时给出学派树与时代轴两个宏观视图，并通过相对路径双向链接到各条目与上层 `skills/philosophy-frameworks/` 下的可执行技能卡片，形成「概念 ↔ 思想家 ↔ 分析技能」的三层引用网络。
