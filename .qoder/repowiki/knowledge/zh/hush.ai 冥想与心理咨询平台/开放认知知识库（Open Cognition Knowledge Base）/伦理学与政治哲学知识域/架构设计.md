纯文档型知识模块，按「双轴」组织：
- `schools/` 下按学派（consequentialism / deontology / virtue-ethics / social-contract / critical-theory / care-ethics 等）再细分到具体思想家条目；
- `concepts/` 下存放跨学派的抽象概念（categorical-imperative、veil-of-ignorance、virtue 等），供多学派交叉引用。
根目录 `README.md` 充当索引树，列出所有学派与概念并链接到对应 `.md`，同时汇总关联的 `skills/ethics-politics-frameworks/*` 分析工具。
每个条目使用统一的 YAML front matter（`id`、`title`、`type`、`domain`、`school`、`era`、`tags`、`aliases`、`sources`）作为结构化元数据，正文采用固定章节模板（一句话定义 → 提出者与背景 → 核心要义 → 通俗用法 vs 学术原义 → 关系图 → 代表人物/著作 → 应用场景 → 常见误读 → 跨学科关联 → 进阶阅读）。内部通过相对路径 `[概念](../../concepts/xxx.md)` 与 `[思想家](../schools/yyy/zzz.md)` 互相链接，形成无运行时依赖的静态知识网络。
