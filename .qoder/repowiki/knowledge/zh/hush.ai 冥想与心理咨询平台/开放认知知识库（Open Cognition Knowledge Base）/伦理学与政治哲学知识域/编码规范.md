- 每个 `.md` 文件顶部统一使用 YAML front matter 声明 `id/title/type/domain/school/era/tags/aliases/sources` 等字段，作为机器可读的结构化入口。
- 思想家人物条目 `type: thinker` 包含 `birth`/`death` 生卒年与国籍信息，概念条目 `type: concept` 则标注所属 `school` 与时代 `era`。
- 正文遵循固定章节顺序：一句话定义 → 提出者与背景 → 核心要义（关键论点 + 论证结构）→ 通俗用法 vs 学术原义表格 → 与相关概念的关系 → 代表人物/著作 → 应用场景 → 常见误读 → 跨学科关联 → 进阶阅读。
- 跨条目引用一律使用相对路径的 Markdown 链接，并在正文中以 `[同源]`/`[对立]`/`[发展]`/`[平行]` 标签标明关系方向。
- README.md 仅承担索引职责，不承载正文内容，通过层级缩进与反引号代码块展示学派树形结构。
