- 每个 SKILL.md 顶部使用 YAML frontmatter 声明 name/description/domain/tags/linked_thinker/linked_concepts，作为 Agent 检索与路由的唯一契约。
- Skill 正文遵循固定章节顺序：一句话功能 → 何时使用 → 何时不使用 → 理论基础 → 操作流程（Step N + 提问范式）→ 完整示例 → 反例（误用）→ 关联条目。
- 人物条目统一采用 id/title/type/tradition/era/birth/death/tags/aliases/sources frontmatter，并按“基本信息/核心命题/五层蒸馏/代表偈颂/关键著作/常见误读/跨传统关联/关联 Skills”八段结构组织。
- 跨条目链接一律使用相对路径（如 `../../../domains/...`），并在关联旁标注关系类型（`[同源]`/`[发展]`/`[平行]`）。
- 每个 Skill 必须包含“何时不使用”和“反例（误用）”两个 section，明确触发边界与误用后果。
- Wisdom Masters 的五层蒸馏（怎么说话/怎么想/怎么判断/什么不做/知道局限）必须全部出现，且每层信息需映射到对应 SKILL.md 的各 section。
