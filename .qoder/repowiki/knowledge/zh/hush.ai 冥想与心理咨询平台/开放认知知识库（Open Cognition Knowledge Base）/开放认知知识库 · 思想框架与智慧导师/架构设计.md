本模块由三块纯文档子域构成，无代码依赖：
- `skills/`：按领域（philosophy / psychology / sociology / religion / arts / aesthetics / ethics-politics / literature / cognitive-systems）分目录的 SKILL.md 集合，每个 Skill 是独立可被 Agent 调用的操作化流程，通过 YAML frontmatter 声明 `name`/`description`/`domain`/`linked_thinker`/`linked_concepts`/`tags`，并由顶层 README 提供按领域的索引表。
- `wisdom-masters/`：`masters/<region>/` 存放人物条目（慧能、临济、道元等），`skills/<person>-<skill>/` 存放从该人物五层蒸馏（怎么说话/怎么想/怎么判断/什么不做/知道局限）提炼出的具体 Skill；README 规定五层必须完整且双向链接到对应人物与概念。
- `meta/`：`taxonomy.md` 定义三层分类（领域→学派/传统→思想家/概念）、`quality-criteria.md` 给出 PR 审核清单（事实性/完整性/辨析性/互链规范/Skill 专项/风格），`sources.md` 记录来源规范。
依赖方向单向：SKILL.md → domains/ 下的思想家/概念条目；wisdom-masters/skills → wisdom-masters/masters + skills/religion-frameworks；meta 为横切约束不反向引用内容。
