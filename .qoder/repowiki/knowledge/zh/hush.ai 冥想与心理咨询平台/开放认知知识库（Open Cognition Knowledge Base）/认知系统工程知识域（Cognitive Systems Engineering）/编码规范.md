- 所有概念与思想家文档均使用 YAML front matter 声明结构化元数据（id、title、type、domain、school、era、tags、aliases、sources），便于统一检索与聚合。
- 文档内部采用固定章节结构：一句话定义 → 提出者与背景 → 核心要义 → 通俗用法 vs 学术原义 → 与相关概念的关系 → 代表思想家 → 应用场景 → 常见误读 → 跨学科关联 → 进阶阅读。
- 跨文档引用统一使用相对路径（如 `../schools/distributed/leontiev.md` 或 `./distributed-cognition.md`），避免绝对路径。
- tags 字段使用英文小写多词标签（如 activity-theory、bounded-rationality），aliases 同时收录中英文别名以便检索。
