本模块是纯脚本层，不依赖任何 Python 包结构，直接面向仓库根目录运行：
- `start_server.sh`：统一启动入口，通过环境变量 `MEDITATION_POSTGRES_URL` 切换 SQLite（默认 `meditation_local.db`）/ PostgreSQL，并调用 `.venv/bin/python -m uvicorn hushai.meditation.app:get_app --factory` 启动 FastAPI。
- `test_api.py` / `test_local.py`：两个等价的一键测试脚本，均使用 `subprocess.Popen` 拉起同进程内的 `hushai.meditation.app`，轮询 `/health` 后以 httpx 依次验证微信登录、知识导入/搜索、对话记忆、用户档案等核心链路；当未配置 WX_APPID 时回退到直连 `get_session_factory()` + `_create_token` 注入测试用户。
- `frontend_qa.py`：基于标准库 `html.parser.HTMLParser` 对 `hushai/meditation/static/index.html` 做 HTML 标签平衡、重复 ID、CSS 变量/媒体查询/选择器复杂度、JS IIFE 包裹、localStorage 键、响应式断点、ARIA 无障碍及资源加载等静态质量检查。
- `import_open_cognition.py`：仅作为旧入口兼容壳，转发到 `hushai.meditation.commands.init_knowledge.main`。
依赖方向单向指向 `hushai.meditation.*` 产品代码，脚本之间互不引用。
