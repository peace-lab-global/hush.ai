仓库采用「领域→学派/传统→思想家/概念」三层分类（见 meta/taxonomy.md），共 7 个领域目录 domains/{philosophy,religion,sociology,psychology,ethics-politics,aesthetics,cognitive-systems}，每个领域下分 schools/<流派>/<人物>.md 与 concepts/<概念>.md；另设独立的 arts/ 与 literature/ 子域。

Skill 层独立于知识层：skills/<domain>-frameworks/<skill>/SKILL.md 以 YAML frontmatter（name/description/domain/linked_thinker/linked_concepts/tags）声明可被 Agent 直接索引的操作框架，并通过相对路径反向链接到对应 thinker/concept 条目，形成「知识条目 → 操作技能」的单向依赖方向。

辅助层包括：templates/（thinker/concept/skill/thinker 四类模板）、meta/（taxonomy、quality-criteria、sources）、reports/（各阶段执行报告与 gap analysis）、visualization/（HTML/SVG 可视化产物）、wisdom-masters/（高僧五层框架蒸馏出的独立 skill 集合，复用 skills/religion-frameworks 下的通用框架）。index.json 作为机器可读的全库索引，聚合 entries 列表供外部工具消费。
