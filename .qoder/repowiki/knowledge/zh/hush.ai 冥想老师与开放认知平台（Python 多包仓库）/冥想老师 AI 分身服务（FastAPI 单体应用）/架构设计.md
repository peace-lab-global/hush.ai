app.py 中的 `create_app()` 是唯一的装配点：在 lifespan 中依次初始化 DB、默认管理员与默认导师/预约配置，随后通过 `include_router` 把 api_routes 下的各模块路由与管理后台 admin_ui 的 Jinja2 页面注册到同一 FastAPI 实例；core_engine 作为业务内核被 api 路由调用，database_layer 提供异步 SQLAlchemy + ChromaDB 持久化能力，admin_ui 与 api 共享 db.models 与 schemas.py 的数据契约。`__main__.py` 暴露 `python -m hushai.meditation` 启动器，内部委托 app.run() 使用 uvicorn 运行。静态资源通过 `StaticFiles` 挂载 `/static` 与 `/admin/static`，Swagger 文档置于 `/debug`，健康检查 `/health`。
