模块以 `engine.py` 为入口，暴露 `chat` / `chat_stream` / `knowledge_qa` 三个异步函数，每个函数内部按固定流水线执行：
- 通过 `db.session.get_session_factory()` 获取 `AsyncSession`，在 try/except 中统一 commit/rollback；
- 调用 `safety.check_safety` 做前置拦截，命中则直接返回安全提示而不走 LLM；
- `_prepare_turn_context` 并行组装 system prompt：从 `memory.get_memory_context_for_prompt`、`knowledge.get_knowledge_context_for_prompt`、`skills.get_skills_context_for_prompt`、`scenes.get_scene_context_for_prompt` 拉取上下文，再经 `prompt.build_system_prompt` 拼接；
- 持久化用户消息后调用 `llm.chat_completion` / `chat_completion_stream`，随后 `_maybe_extract_and_title` 按 `_MEMORY_EXTRACTION_INTERVAL=2` 周期触发 `memory.extract_memories` + `store_memories`。

依赖方向单向向外：本模块只读 `hushai.meditation.db.models` 和 `hushai.meditation.db.vector`，不反向被 core 内其他文件引用；各子模块职责清晰——`llm.py` 基于 openai.AsyncOpenAI 提供多 provider 自动降级（deepseek→zhipu→kimi→openai），`memory.py` 用向量库做语义检索，`knowledge.py` 负责 Markdown frontmatter 解析与分块入库，`safety.py` 用编译期绑定的正则规则表做快速阻断，`wechat_pay.py` 独立封装微信 v3 统一下单/退款/回调验签。`encryption.py`、`remote_knowledge.py` 作为辅助工具由上层按需引入。
