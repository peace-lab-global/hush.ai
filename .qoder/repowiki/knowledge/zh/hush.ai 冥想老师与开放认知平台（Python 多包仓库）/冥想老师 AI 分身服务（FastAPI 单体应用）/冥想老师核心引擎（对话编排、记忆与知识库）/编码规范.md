- 所有对外异步函数采用 keyword-only 参数风格（`async def chat(*, user_id: str, message: str, ...)`），便于扩展且避免位置参数歧义。
- 数据库访问一律通过 `get_session_factory()` 获取 `AsyncSession`，并在 try/except 中显式 commit 或 rollback，禁止裸 `session.execute`。
- LLM 调用统一走 `core.llm.chat_completion` / `chat_completion_stream`，禁止直接实例化 OpenAI 客户端，确保 provider 降级与 mock 行为一致。
- 外部服务调用（向量库、微信支付）失败时记录 warning 日志并返回空结果或抛出 RuntimeError，不在上层吞掉异常。
- Prompt 模板集中定义在 `prompt.py` 的常量字符串中，通过 `build_system_prompt` / `build_knowledge_qa_prompt` 组合注入，禁止在业务逻辑里拼字符串。
