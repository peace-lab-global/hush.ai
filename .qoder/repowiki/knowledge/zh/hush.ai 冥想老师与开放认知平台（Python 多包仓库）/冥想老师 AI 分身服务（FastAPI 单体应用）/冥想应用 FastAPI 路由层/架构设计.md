本模块是 hushai.meditation 应用的 HTTP 边界，每个业务域一个文件（login/auth/chat/counseling/knowledge/skills/teachers/memory/counselor_dashboard/admin/frontend），各自通过 `APIRouter(prefix=..., tags=[...])` 暴露一组 RESTful 端点，由上层 app 聚合挂载。

- 认证子层：auth.py 集中实现微信 OAuth code2session、JWT access/refresh token 签发与校验、bcrypt 哈希 + SHA-256 selector 的 DoS 安全刷新流程；各路由通过 `_require_user` / `_require_knowledge_operator` 等本地依赖注入函数复用 `extract_bearer_token` + `get_current_user_id` 完成鉴权。
- 会话层：所有写操作使用 `Depends(get_session)` 获取异步 SQLAlchemy session，读路径直接执行 select，写路径在 try 块内 flush/commit，异常统一转为 `HTTPException`。
- 外部依赖方向：仅向上依赖 `hushai.meditation.core.*`（chat/engine、wechat_pay、knowledge、encryption）、`db.models`、`schemas`、`admin.auth.verify_admin_token`；不反向依赖其他 api 文件，保持路由间解耦。
- 特殊入口：frontend.py 提供开发模式 `/` 静态页面与 `/api/auth/dev-login` 快速创建用户并签发 JWT；counseling.py 内置微信支付回调 `/orders/pay/notify` 签名校验与订单状态落库。
