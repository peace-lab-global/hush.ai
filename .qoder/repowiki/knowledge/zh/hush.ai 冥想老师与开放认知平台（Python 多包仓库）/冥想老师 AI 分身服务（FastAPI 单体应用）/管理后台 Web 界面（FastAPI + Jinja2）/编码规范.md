- 每个资源页面模块只定义一个 `router = APIRouter(tags=["admin-web"])`，并在 `pages/__init__.py` 的 `build_router()` 中集中 include，禁止跨模块互相引用路由。
- 页面 GET 路由统一先调用 `get_admin_from_request(request)`，未登录时返回 `login_redirect()`；POST/PUT/DELETE 等写操作则抛 401 HTTPException，区分页面重定向与 API 错误语义。
- 数据库访问一律通过 `Depends(get_session)` 获取 `AsyncSession`，并使用原生 `sqlalchemy.select` 构建查询，不在本模块内封装 service 层。
- HTML 响应统一通过 `templates.TemplateResponse(request, "xxx.html", {...})` 渲染，模板变量名与模板文件名保持一一对应。
- 需要表单提交的 POST 路由同时使用 `@require_admin` 与 `@require_csrf` 装饰器，确保既校验管理员身份又校验 CSRF token。
