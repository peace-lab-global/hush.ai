本模块为纯 Markdown 文档目录，按主题划分：根级 `README.md` 作为索引表；`deployment-minimal.md` 与 `deployment.md` 分别提供 venv + uvicorn 的最小路径与 systemd/Nginx 分阶段完整路径；`configuration.md` 描述环境变量与 JSON 字段、五种对话模式（含 `pua`）及模式别名；`cli.md` 记录 `hush` / `python -m hushai` 的 TTY/管道/REPL 分支与退出码；`architecture.md` 以表格+mermaid 流程图梳理 `hushai.cli` → `settings` → `llm` → `postprocess` 的职责边界与请求链路；`development.md` 沉淀 RAG/Skills/配置管理/对话追溯的实现落点与验证方法；`reports/2026-05-31-project-status.md` 与 `evaluation-report-frontend-backend.md`、`web-ui-improvements.md` 存放阶段性评估与改进记录；`reference/xiaoe-psychology-dashboard.png` 为 UI 截图素材。文档之间通过相对链接互相引用，无构建脚本或渲染管线。
