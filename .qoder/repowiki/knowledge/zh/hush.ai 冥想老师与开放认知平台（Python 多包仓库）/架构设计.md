根目录作为多子模块的编排层：
- `pyproject.toml` 定义单包 `hushai`，通过可选依赖 `[meditation]` 把 FastAPI 冥想服务（`hushai.meditation`）、CLI（`hushai.cli`）与 Alembic/ChromaDB 等运行时解耦；`[project.scripts]` 暴露 `hush`、`hush-meditation`、`hush-init-knowledge` 三个可执行入口。
- `Makefile` 是跨子模块的统一工作流：`install/dev/fmt/lint/typecheck/test/security/check/build/clean` 对 `hushai` 与 `tests` 同时生效，确保 CLI、meditation 与 tests 共享同一套 ruff/mypy/bandit/pytest 配置。
- `docker-compose.yml` 提供 Postgres + ChromaDB 双依赖，供 meditation 子模块本地运行与测试使用。
- `scripts/` 与 `tests/` 分别面向运维脚本与 pytest 用例，二者都通过 `hushai` 包的相对导入访问同一源码树，形成“源码即测试数据源”的闭环。
- `docs/` 与 `knowledge_base/` 作为纯 Markdown/YAML 资产，被 meditation 服务的 `init_knowledge` 命令在启动时消费，构成“文档即知识”的数据契约。
