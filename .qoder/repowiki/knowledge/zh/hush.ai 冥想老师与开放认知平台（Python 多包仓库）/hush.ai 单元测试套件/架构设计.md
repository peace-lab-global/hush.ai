- 顶层 `conftest.py` 提供全局 fixture：`_reset_settings`（autouse，通过 `monkeypatch.delenv` + `hushai.settings.reset_for_tests()` 清理 HUSH_MODE/HUSH_CALM_MODE）、`meditation_session`（内存 SQLite + aiosqlite + StaticPool，自动建表 Base.metadata.create_all，供需要真实 ORM 的异步测试使用）、`meditation_config`（注入带 jwt_secret 的 MeditationConfig 并在 yield 后 reset）。
- 顶层测试文件按子系统划分：`test_cli.py` 验证命令行入口与 REPL；`test_llm.py` / `test_llm_errors.py` 用 `unittest.mock.MagicMock` 伪造 OpenAI 客户端；`test_postprocess.py` / `test_settings.py` 分别覆盖输出后处理与配置合并逻辑。
- `tests/meditation/` 子包对应 `hushai.meditation` 源码目录，每个被测源文件有同名 `test_*.py`（auth、core、engine、engine_safety、export、llm_core、prompt、safety、schemas、vector），并通过本地 `_test_config` autouse fixture 或继承根级 `meditation_session`/`meditation_config` 完成依赖注入。
- 所有外部 I/O（OpenAI HTTP、文件系统、终端 stdin）均通过 `unittest.mock.patch` 或 `monkeypatch.setattr` 替换，确保纯单元测试、零网络依赖。
