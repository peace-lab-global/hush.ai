根目录作为跨子模块的编排层，核心契约由 `pyproject.toml` 与 `Makefile` 共同定义：
- 单包分发：`[project]` 暴露 `hushai` 包，通过 `[project.optional-dependencies]` 把 FastAPI 冥想服务（`meditation`）、CLI（`cli`）与 Alembic/ChromaDB 等运行时解耦；`[project.scripts]` 注册 `hush`、`hush-meditation`、`hush-init-knowledge` 三个可执行入口。
- 统一工具链：`Makefile` 的 `install/dev/fmt/lint/typecheck/test/security/check/build/clean` 对 `hushai` 与 `tests` 同时生效，确保 CLI、meditation 与 tests 共享同一套 ruff/mypy/bandit/pytest 配置。
- 本地依赖栈：`docker-compose.yml` 提供 Postgres + ChromaDB 双容器，供 meditation 子模块本地运行与测试使用。
- 源码即数据源：`scripts/` 与 `tests/` 都通过 `hushai` 包的相对导入访问同一源码树；`docs/` 与 `knowledge_base/` 作为纯 Markdown/YAML 资产被 meditation 服务的 `init_knowledge` 命令在启动时消费，形成“文档即知识”的数据契约。
- 新增咨询师服务将沿用此模式：作为 `hushai.meditation` 下的新子包，复用同一数据库、Alembic 迁移与 FastAPI 路由装配流程。
