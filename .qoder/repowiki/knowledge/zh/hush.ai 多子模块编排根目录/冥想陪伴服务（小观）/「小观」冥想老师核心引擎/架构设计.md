模块以 `engine.py` 为唯一对外入口，暴露 `chat` / `chat_stream` / `knowledge_qa` 三个异步函数，每个函数遵循统一流水线：通过 `db.session.get_session_factory()` 获取 `AsyncSession`，在 try/except 中 commit/rollback；先调用 `safety.check_safety` 做前置阻断（命中则直接返回安全提示）；再经 `_prepare_turn_context` 并行拉取 memory/knowledge/skills/scenes 上下文，由 `prompt.build_system_prompt` 拼接 system prompt；随后走 `llm.chat_completion` / `chat_completion_stream`，最后按 `_MEMORY_EXTRACTION_INTERVAL=2` 周期触发 `memory.extract_memories` + `store_memories`。

子模块职责清晰且单向依赖：
- `llm.py`：基于 `openai.AsyncOpenAI` 的多 provider 自动降级（deepseek→zhipu→kimi→openai），debug 无 key 时回退到 `_mock_chat_completion`；
- `memory.py`：用 LLM 从对话中提取结构化记忆，写入 `Memory` 表并通过 `hushai.meditation.db.vector` 做向量检索；
- `knowledge.py`：解析 Markdown frontmatter、分块入库，提供 RAG 检索接口；
- `safety.py`：编译期绑定的正则规则表，按 `crisis`/`emergency` 两级快速阻断；
- `wechat_pay.py`：独立封装微信 v3 Native/JSAPI 下单、查询、退款及回调验签；
- `encryption.py`、`remote_knowledge.py`、`scenes.py`、`skills.py`、`prompt.py` 作为辅助工具被上层按需引入。

依赖方向单向向外：本模块只读 `hushai.meditation.db.models` 和 `hushai.meditation.db.vector`，不被 core 内其他文件反向引用。
