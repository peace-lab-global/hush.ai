本模块是 hushai.meditation 应用的 HTTP 入口，采用「一域一文件」扁平结构：auth.py 集中实现微信 OAuth code2session、JWT access/refresh token 签发与校验、bcrypt + SHA-256 selector 的 DoS 安全刷新流程；login.py 暴露 /api/login 作为外部认证入口；chat/counseling/knowledge/skills/teachers/memory/admin/frontend 各自定义 `router = APIRouter(prefix=..., tags=[...])` 并通过上层 app 聚合挂载。

- 鉴权子层：各路由通过本地 `_require_user` / `_require_admin` 依赖注入函数复用 auth.py 的 `extract_bearer_token` + `get_current_user_id`，admin 路由额外支持 `verify_admin_token` 回退，形成「用户 → 管理员」双层鉴权。
- 会话层：所有写操作使用 `Depends(get_session)` 获取异步 SQLAlchemy session，try 块内 flush/commit，异常统一转为 `HTTPException`；列表查询用 `select(...).subquery()` + `func.count()` 计算 total 后 offset/limit 分页。
- 外部依赖方向：仅向上依赖 `hushai.meditation.core.*`（chat/engine、wechat_pay、knowledge、encryption）、`db.models`、`schemas`、`db.session.get_session`、`admin.auth.verify_admin_token`；路由间不互相 import，保持解耦。
- 特殊入口：frontend.py 提供开发模式 `/` 静态页面与 `/api/auth/dev-login` 快速创建用户并签发 JWT；counseling.py 内置微信支付回调 `/orders/pay/notify` 签名校验与订单状态落库。
