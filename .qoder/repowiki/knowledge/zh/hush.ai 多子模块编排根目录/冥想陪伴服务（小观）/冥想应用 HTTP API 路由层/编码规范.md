- 每个路由文件顶部以单行 docstring 说明职责，并在文件级定义 `router = APIRouter(prefix=..., tags=[...])` 作为该域的端点集合。
- 受保护接口统一通过本地 `_require_user` / `_require_admin` 依赖注入函数从 Authorization Header 提取 Bearer token 并解析出 user_id，再作为参数传入 handler。
- 列表查询采用 `select(...).subquery()` 配合 `func.count()` 计算 total，再用 offset/limit 分页，返回包含 total 的 Response 模型。
- 业务异常一律抛出 `RuntimeError`，在路由层捕获后转换为对应 HTTP status 的 `HTTPException(detail=str(e)) from None`，避免 traceback 泄露。
- 写入类接口在 try 块末尾显式 `await session.commit()`，读取类接口不 commit，遵循 FastAPI 默认事务语义。
- 需要管理员或普通用户双重鉴权的接口使用 `_require_admin`，先尝试 `verify_admin_token`，失败再回退到 `get_current_user_id`。
