- 入口 `admin/__init__.py` 仅暴露 `router = build_router()`，供上层 `app.py` 以 `from hushai.meditation.admin import router` 方式挂载，兼容历史引用。
- `pages/` 子包按资源拆分为独立模块（`users.py`、`conversations.py`、`memories.py`、`knowledge.py`、`skills.py`、`scenes.py`、`orders.py`、`appointments.py`、`counselors.py`、`audit.py`、`export.py`、`settings.py`、`dashboard.py`、`auth.py`、`admin_users.py`），每个模块定义一个同名的 `APIRouter(tags=["admin-web"])`；`pages/__init__.py` 的 `build_router()` 统一聚合并挂到 `/admin` 前缀。
- 鉴权与 CSRF 集中在 `admin/auth.py`：通过 cookie `admin_token` / `Authorization: Bearer` 解析 JWT（`jose.jwt`，算法取自配置），提供 `get_admin_from_request`、装饰器 `require_admin`、`require_csrf`，以及 `init_default_admin` 初始化默认管理员。
- 页面层公共能力抽离到 `pages/_shared.py`：Jinja2 模板引擎（目录固定为 `templates/`）、`require_admin_page` / `require_admin_api` 依赖、`get_stats_context` 统计上下文、`BatchDeleteRequest` / `LoginRequest` Pydantic 模型等，消除各页面重复样板。
- 模板位于 `templates/`，静态资源在 `static/{css,js}`，由 `Jinja2Templates(directory=...)` 直接加载，避免依赖进程 cwd。
- 数据访问使用 SQLAlchemy async select，通过 `Depends(get_session)` 注入 `AsyncSession`，不引入 ORM service 层，页面函数直接执行业务查询。
