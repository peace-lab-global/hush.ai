# 冥想老师 AI - 管理后台

基于 Web 的管理后台界面，用于管理冥想老师 AI 服务的用户、对话、记忆和知识库。

## 功能特性

### 📊 仪表盘
- 系统统计概览（用户数、对话数、消息数、记忆数、知识条目）
- 最近注册用户
- 最近对话记录

### 👥 用户管理
- 用户列表（支持搜索）
- 用户详情页
- 启用/禁用用户
- 查看用户记忆和对话

### 💬 对话管理
- 对话记录列表（支持按用户筛选）
- 对话详情页（查看完整聊天记录）

### 🧠 记忆管理
- 用户记忆列表（支持按用户/分类筛选）
- 删除记忆条目

### 📚 知识库管理
- 知识条目列表（支持搜索）
- 知识详情查看
- 删除知识条目

## 访问方式

启动冥想服务后，访问：

```
http://localhost:8000/admin
```

## 登录配置

默认管理员账号：
- 用户名：`admin`
- 密码：`admin`

建议通过环境变量设置安全的密码：

```bash
export MEDITATION_ADMIN_USERNAME=your_username
export MEDITATION_ADMIN_PASSWORD=your_secure_password
```

## 技术栈

- **后端**: FastAPI + Jinja2
- **前端**: 原生 HTML + CSS + JavaScript
- **样式**: 自定义 CSS（现代简洁风格）
- **图标**: Font Awesome

## 安全特性

- JWT Token 认证
- Cookie + Header 双支持
- 24小时 Token 有效期
- HttpOnly Cookie

## 界面预览

### 登录页
简洁的登录界面，支持错误提示。

### 仪表盘
卡片式统计展示，数据一目了然。

### 数据表格
统一的数据表格样式，支持分页和搜索。

适配桌面和移动设备。
