说明

通过 JSON 一次导入多条技能。每条技能包含注入模型的正文（content），前台用户勾选后会在系统提示中作为「加持」生效。

  • 必填字段：name、content；可选：description（前台展示）、sort_order（数字，越小越靠前）、is_active（默认 true）。
  • 支持两种 JSON 根结构：{"skills": [ ... ]} 或顶层数组 [ ... ]。
  • 单次最多导入 100 条。

JSON 粘贴导入

文件导入（.json）

拖拽 JSON 文件到此处，或 点击选择

API

  • POST /api/skills/import — JSON Body
  • POST /api/skills/import-file — multipart 上传 file

需携带 Authorization: Bearer（管理员或用户 Token）。后台页面使用管理员 Cookie。
