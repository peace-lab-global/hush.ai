Markdown 与对话检索（RAG）

导入的 Markdown 会写入数据库并写入向量库，用户在前台对话时，系统会按问题自动检索相关片段，注入到「相关理论参考」中参与回答。

  • 支持 .md / .markdown 文件；也可上传 .txt 并勾选「按 Markdown 解析」。
  • 支持 YAML frontmatter（title、tags）；正文会转为纯文本后分块与向量化，便于检索。
  • 纯文本粘贴时勾选「按 Markdown 解析」即可粘贴带 # 标题、列表的文档。

API 接口

知识库导入也可以通过 API 接口调用：

  • POST /api/knowledge/import - 导入文本内容
  • POST /api/knowledge/import-file - 导入文件
  • POST /api/knowledge/import-structured - 导入结构化数据
  • POST /api/knowledge/search - 搜索知识库
